# Ragnarok
Microtuff Solutions offensive security toolchain.

## Modules
- `firmware/` — firmware extraction, bootchain analysis, embedded device recon
- `network/` — network enumeration, exploit prototyping, payload delivery
- `redteam/` — red team automation, phishing, C2 stubs, detection evasion
- `utils/` — shared helpers: logging, config, crypto, transport

## Rules
- Research and authorized testing only.
- No malware/RAT builds. Detection, monitoring, hardening, and analysis only.
