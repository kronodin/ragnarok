# Ragnarok Honeypot Module

Decoy service emulators for unauthorized access detection and threat intelligence.

## Modules
- `http/` — HTTP/HTTPS honeypot with fake admin panels, login forms, and juicy endpoints
- `ssh/` — SSH banner and weak-auth emulator
- `logs/` — JSONL capture, PCAP export, alerting hooks
- `config/` — profiles, whitelist, alert rules

## WARNING
Deploy only on networks you own or have written authorization to monitor.
