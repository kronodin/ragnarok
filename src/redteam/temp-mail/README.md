# Ragnarok Temp-Mail Engine

Lightweight temporary email generation and retrieval for authorized red team assessments only.

## WARNING
Use only against targets you own or have explicit written authorization to test.
Unauthorized email generation/harvesting is illegal.

## Providers
- mail.tm
- guerrillamail
- dropmail.me

## Usage
See `engine.py` for API wrappers and `cli.py` for command-line usage.
